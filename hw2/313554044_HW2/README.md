## ⚙️ Setup and Prerequisites

### 1. Habitat Environment

This project requires the installation of **Habitat-Sim** (Simulation) and its dependencies.

### 2. Data Files

The following data files must be placed in the project directory (`src/`):

* `semantic_3d_pointcloud/point.npy`
* `semantic_3d_pointcloud/color01.npy` (or `color0255.npy`)
* `color_coding_semantic_segmentation_classes.xlsx`

### 3. Generated Map Files (Part 1 Output)

The following files must be present **before running Part 2 or Part 3**:

* `map100.png` (2D semantic map generated by `part1_load_point.py`)
* `coordinate_bounds.json` (World coordinate bounds generated by `part1_load_point.py`)

## ▶️ Execution Steps

The entire pipeline must be executed sequentially. We will use `part1_load_point.py` to generate the necessary map files, and then `part3.py` to handle the RRT* path planning, user interaction, and robot navigation.

### Step 1: Generate 2D Map and Coordinate Bounds (Part 1)

Run the map generation script. This script performs floor/ceiling removal and saves the 2D projection and coordinate bounds.

```bash
python part1_load_point.py
````

**Output:**

1.  `map100.png` (The 2D semantic map required for RRT).
2.  `coordinate_bounds.json` (Used for Pixel-to-World conversion in Part 3).

### Step 2: RRT\* Path Planning and Robot Navigation (Part 2 & 3)

The `part3.py` script integrates the RRT\* algorithm, user interaction (selecting the target object and start point), and the Habitat control loop.

```bash
python part3.py
```

**Interaction Flow:**

1.  **Target Selection:** The console will prompt you to enter a target semantic class (e.g., `rack`, `cooktop`).
2.  **Instance Selection:** A matplotlib window will open, showing all instances of the chosen class. **Click the target instance** to select it.
3.  **Start Point Selection:** The matplotlib window will prompt you to **click a starting position** on the map.
4.  \**RRT* Execution:\*\* The RRT\* algorithm (`rrt_star.py`) runs on the background to find an optimal, safe path between the selected points.
5.  **Navigation:** The Habitat simulator starts, and the agent executes the path using the Pure Pursuit controller. The visualization window (`Navigation (Overlay)`) shows the agent's view with the target object highlighted by a transparent mask.

**Output:**

1.  `rrt_star_result_{target_class}.png` (Visualization of the calculated path).
2.  `{target_class}_navigation.mp4` (Video recording of the navigation).
