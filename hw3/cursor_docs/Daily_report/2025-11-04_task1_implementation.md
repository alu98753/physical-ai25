1. **正確應用經典 D-H 慣例**

   - 變換順序：Rot_z(θ) → Trans_z(d) → Trans_x(a) → Rot_x(α)
   - 矩陣乘法順序準確

2. **保存中間變換矩陣**

   - 使用列表儲存 T_0 到 T_6 的所有變換
   - 為雅可比計算提供必要的資料

3. **正確計算幾何雅可比**

   - 提取 z 軸：T[0:3, 2]
   - 提取位置：T[0:3, 3]
   - 線速度部分：J_v = z × (p_E - p)
   - 角速度部分：J_ω = z

4. **注意細節**
   - 使用未調整的末端位置 p_E 計算雅可比
   - adjustment 矩陣由框架自動應用
